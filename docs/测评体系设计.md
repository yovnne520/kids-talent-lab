# 童画天赋实验室 · 测评结果分析体系设计

> 产品一句话：上传孩子的一幅画 + 30 秒问卷，AI 生成专属天赋报告，家长一键生成体面的晒娃分享卡。

---

## 一、设计原则（三条铁律）

来自上一轮分析的结论，本产品必须同时满足：

1. **夸得具体**：文案必须引用真实数据（"AI 在画面中识别出 17 种色相"），让夸奖可信、可传播。
2. **结果可用**：每个维度都给出家长当天就能执行的动作（不空谈"多陪伴"）。
3. **晒得体面**：分享卡是产品本体，不是附属功能——家长转发它 = 免费投广告，且晒孩子没有"自夸"的心理负担。

分数设计铁律：**天赋指数永远落在 78–96 区间**。低了得罪用户（家长无法接受"孩子没天赋"），满了没有提升空间（接不住后续建议与导流）。

---

## 二、测评流程

```
欢迎页 → 基本信息（昵称+年龄）→ 12 题行为问卷（约 40 秒）
→ 画作上传（可选，强引导）→ AI 分析动画（3-4 秒）→ 结果页 → 生成分享卡
```

- 问卷单独可用；上传画作会"解锁更精准分析"（结果页反向提示，制造二次使用钩子）。
- 全程 < 1.5 分钟，无注册、无付费、无跳转。

---

## 三、六维度体系

| 维度 | key | 定义 | 数据来源 |
|---|---|---|---|
| 色彩感知力 | color | 对颜色的敏感度与运用能力 | 问卷 + 画作 |
| 观察表现力 | observe | 捕捉细节、抓住事物特征的能力 | 问卷 + 画作 |
| 想象创造力 | imagine | 跳出常规、创造新形象的能力 | 问卷 + 画作（辅助） |
| 情感表达力 | express | 用画面传递情绪的能力 | 问卷 + 画作 |
| 专注执行力 | focus | 投入度与坚持完成的能力 | 仅问卷（单幅画无法测量） |
| 审美构图力 | aesthetic | 布局意识与画面美感 | 问卷 + 画作 |

---

## 四、问卷题库（12 题 × 5 档：从不/很少/偶尔/经常/总是）

| # | 题目 | 映射维度 |
|---|---|---|
| 1 | 画画时会自己混色、调色，而不是只用现成的颜色 | color |
| 2 | 画里常出现别人没注意到的细节（小猫的胡须、窗户里的灯） | observe |
| 3 | 讲自己的画时能编出完整的故事或情节 | imagine |
| 4 | 心情好坏会明显反映在画里（开心时色彩明亮，难过时偏暗） | express |
| 5 | 一幅画能安静画 40 分钟以上不中断 | focus |
| 6 | 画面布局有想法（主体居中、天空地面分层），不是随手涂 | aesthetic |
| 7 | 会指着晚霞、树叶说"这个颜色真好看" | color |
| 8 | 会画出真实世界没有的东西（会飞的鱼、长翅膀的车） | imagine |
| 9 | 画完会主动讲"我画的是什么" | express |
| 10 | 照着实物画时能抓住主要特征（画爸爸会画出眼镜/胡子） | observe |
| 11 | 不满意会重画或修改，追求"画好" | focus |
| 12 | 会评价别的画"这个好看 / 这个颜色怪" | aesthetic |

计分：每档 1–5 分线性映射为 0–100，维度分 = 所属题目均值。

## 五、画作分析算法（浏览器本地 Canvas，不上传服务器）

| 特征 | 提取方法 | 映射维度 |
|---|---|---|
| 色相丰富度 | 12 色相桶统计（排除纸面白与深黑） | color（60%）+ imagine（辅助） |
| 饱和度均值 | HSL 饱和度 | color（40%）+ express |
| 亮度均值 | HSL 亮度 | express |
| 暖色占比 | 色相落在红/橙/黄区间的比例 | express（情绪热烈度） |
| 边缘密度 | 相邻像素亮度差阈值法（笔触/细节量） | observe |
| 内容覆盖率 | 非纸面像素占比（理想带 35%–75%） | aesthetic |
| 构图重心偏移 | 内容质心与画面中心的距离（略偏最佳） | aesthetic |
| 色相熵 | 色相分布的信息熵 | imagine |
| 主色板 | 色相桶平均色取 Top5 | 结果页展示 + 分享卡 |

算法特征归一化后缩放到 70–96 区间（与"不低不满"铁律一致）。

## 六、评分合成模型

```
维度分（有画作）= 问卷分 × 0.55 + 画作分 × 0.45
维度分（无画作）= 问卷分
维度分 clamp 到 [72, 97]
天赋指数 = 六维度等权平均，clamp 到 [78, 96]
百分位 = 线性映射到 "超越 68%–94% 的同龄小艺术家"
```

**天赋类型判定**：
- 六维方差 < 8 且均分 ≥ 84 → 「六边形战士型」
- 否则取最高维度定型，平分按 color > imagine > observe > express > aesthetic > focus 优先级

## 七、天赋类型系统（7 型）

| 类型 | 称号 | 主导维度 | 分享卡主打句 |
|---|---|---|---|
| 色彩大师型 | 色彩魔法师 🎨 | color | 别人看到的是颜色，ta 看到的是情绪的光谱 |
| 故事叙述型 | 故事造梦师 🌙 | imagine | 每幅画都是一个平行宇宙的入口 |
| 观察入微型 | 细节侦探 🔍 | observe | 世界偷偷藏起来的细节，都被 ta 画了下来 |
| 情感表达型 | 心灵画语者 💗 | express | ta 说不出口的话，都在画里说完了 |
| 构图美学型 | 小小美学家 🏛️ | aesthetic | 天生的画面导演，懂得取舍与留白 |
| 沉浸专注型 | 深度创作家 ⏳ | focus | 一旦拿起画笔，就进入自己的心流世界 |
| 六边形战士型 | 全能艺术家 ⭐ | 均衡 | 没有明显短板的六边形战士，潜力无限 |

## 八、文案策略（巴纳姆结构 = 具体观察 + 普遍真话 + 专属建议）

每段解读文案三段式：
1. **具体观察**（真实数据背书）："AI 在画面中识别出 9 种色相，暖色占比 62%——这个数据超过大部分同龄孩子。"
2. **普遍真话**（巴纳姆句式，人人觉得"说的就是我娃"）："ta 不是在乱涂，而是在做色彩实验；那些'涂出线'的地方，恰恰是探索边界的证据。"
3. **专属建议**（当天可执行）："本周和孩子玩一次'调色侦探'：只给红黄蓝三色，让 ta 调出晚餐桌上的橙色。"

无画作时降级为纯问卷文案（去掉数据引用，保留夸与建议）。

## 九、分享卡设计（核心传播物）

- 尺寸 750×1334（手机竖版，微信/小红书友好）
- 内容结构：品牌头图 → 昵称+称号 → 天赋指数环形图 → 雷达图 → Top3 优势条 → 孩子画作缩略图 → 主色板色卡 → 百分位金句 → slogan「每个孩子都是天生的艺术家」→ 引导语「测测你家宝贝」
- 一键保存 PNG；转发场景默认"晒图 + 自嘲式免责"（"AI 说的，不是我说的"），转发零心理负担

## 十、隐私与合规

- 照片分析全程在浏览器本地完成，**不上传任何服务器**（这是卖点，明示在页面）
- 页脚免责声明：娱乐性测评，仅供参考，不构成专业教育建议
- 无用户系统、无数据收集，静态托管即可运行

## 十一、变现与私域接口（给品牌定制版预留）

- 分享卡底部预留二维码位（品牌课程 / 私域入口）
- 结果页"深度发展建议"区块可替换为课程/画材导流卡片
- 定制版逻辑不变，只换文案库与二维码 → 可作为给母婴/美术教育客户的交付模板
