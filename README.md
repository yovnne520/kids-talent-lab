# 🎨 童画天赋实验室

AI 儿童天赋测评网站：上传孩子的一幅画 + 30 秒问卷，生成六维天赋报告、专属培养建议与可分享的天赋报告卡。

## 产品逻辑

- **夸得具体**：文案引用真实画面数据（"AI 识别出 7 种色相，暖色占比 62%"）
- **结果可用**：每个维度附当天可执行的亲子建议
- **晒得体面**：一键生成竖版分享卡（PNG），晒孩子零自夸负担
- **分数铁律**：天赋指数恒在 78-96 区间（详见 `docs/测评体系设计.md`）

## 技术特性

- 纯静态站（HTML/CSS/JS，零依赖，无需构建）
- 画作分析全程在浏览器本地 Canvas 完成（色彩量化、色相熵、笔触边缘密度、构图重心），**照片不上传任何服务器**
- 分享卡由 Canvas 本地生成 PNG 下载

## 目录结构

```
├── index.html          页面骨架（六屏流程）
├── css/style.css       样式
├── js/
│   ├── data.js         题库 + 七种天赋类型文案库 ★定制入口
│   ├── scoring.js      评分合成引擎（纯函数，可单测）
│   ├── analyze.js      画作特征提取（本地 Canvas）
│   ├── radar.js        雷达图绘制
│   ├── share.js        分享卡生成
│   └── app.js          流程控制
├── docs/测评体系设计.md  测评体系设计文档
└── test/test-scoring.js 评分引擎单测（node test/test-scoring.js）
```

## 本地运行

直接双击 `index.html`，或任意静态服务器：

```bash
npx serve .        # 或 python -m http.server
```

## 定制指南（品牌版）

| 定制项 | 位置 |
|---|---|
| 产品名 / slogan / 引导语 | `js/data.js` 顶部 `PRODUCT` |
| 七种天赋类型文案 | `js/data.js` `TYPES` |
| 六维度夸奖与建议 | `js/data.js` `DIMENSIONS` |
| 分享卡配色 | `js/share.js` `deco` 数组与主色 |
| 品牌二维码 | `js/share.js` 底部绘制区（预留位） |
